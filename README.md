# 💼 Amna Ishaq — Portfolio

My personal portfolio website showcasing my projects, skills, and experience as a Full Stack MERN Developer.

**🔗 Live Demo:** https://amnaverse.github.io/amna_portfolio/

## Sections
- 🏠 Home
- 👩‍💻 About
- 🛠️ Skills
- 💼 Experience
- 🚀 Projects (with Live Demo and Code links)
- 📬 Contact

## Features
- 📄 View and download CV
- 🌙 Dark theme with a modern, clean design
- 🔗 Links to LinkedIn, GitHub, and email
- 🚀 Project cards with tech stack tags

## Skills Showcased
HTML5, CSS3, JavaScript (ES6+), React.js, Node.js, Express.js, MongoDB, REST API Design, Bootstrap, Tailwind CSS, Git, GitHub, Postman, VS Code

## Tech Stack
HTML5, CSS3, JavaScript

## How to Run Locally
```bash
git clone https://github.com/amnaverse/amna_portfolio.git
cd amna_portfolio
```
Then open `index.html` in your browser.
